# Frontend de Tareas Express

Aplicación de escritorio en Python con Tkinter, conservada tal como fue proporcionada.

Ejecutar desde esta carpeta con una instalación de Python que incluya Tkinter:

```powershell
cd frontend
python tareas_express.py
```

Esta versión guarda las tareas en `tareas.json` en el directorio de ejecución.
El archivo de datos está excluido de Git. La aplicación todavía no consume la API
de `backend/`.
